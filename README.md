# Гипс и пламя

Витрина мастерской: гипсовый декор, свечи, вазы, тарелочки. Статический сайт на Astro 7 и Tailwind 4. Корзины нет — заказ уходит в Telegram с названием и ценой выбранной вещи.

Живой адрес после публикации: https://blackojack.github.io/gips-i-plamya/

## Команды

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
npm run preview
```

## Как добавить товар

Один товар — одна папка. Вёрстку открывать не нужно.

1. Скопируйте `src/content/products/_primer` в новую папку с латинским именем, например `src/content/products/vaza-rebra`.
2. Положите фотографии рядом с `index.md` и перечислите их имена в `images`. Первая — обложка.
3. Заполните название, цену, категорию, короткую строку и текст. Поставьте `published: true`.
4. Сохраните, закоммитьте и отправьте в `main`: `git add`, `git commit`, `git push`. Через одну-две минуты карточка появится на сайте.

Цена — целое число в рублях. `price: null` показывает «Цену напишем в переписке», а не ноль.

Снять с полки: `published: false`. Удалить совсем: удалить папку.

Показать на главной: `featured: true`. Меньше число в `order` — выше в списке.

Категории: `vases`, `candles`, `plates`, `decor`. Новую полку добавляют в `src/data/categories.ts`.

Папка `_primer` — образец. Её не публикуют.

## Что вписать перед показом мастерской

В `src/config.ts` поле `contacts.telegram` — полная ссылка вида `https://t.me/name`. Пока оно пустое, кнопок «Написать» на сайте нет.

Город, почту и оплату не добавляем, пока их не назвали.

Тексты шагов заказа и абзац о мастерской — в `src/data/content.ts`.

## Публикация на GitHub Pages

1. Репозиторий `BlackoJack/gips-i-plamya`, ветка `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Дальше работает `.github/workflows/deploy.yml`: он сам подставляет адрес и подпапку `/gips-i-plamya/`.

Локально сайт открывается в корне. На GitHub Pages он живёт в подпапке, ссылки это учитывают.
